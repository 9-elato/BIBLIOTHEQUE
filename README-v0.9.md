# My Little Library v0.9 — Warm Game Library

## 실행
1. 기존 v0.8 폴더를 백업합니다.
2. 이 압축파일의 `src/main.jsx`, `src/ArchiveScene.jsx`, `src/style.css`를 기존 프로젝트의 동일 위치에 덮어씁니다. `src/data.js`는 기존 버전 그대로 유지해도 됩니다.
3. VS Code 터미널: `npm.cmd install` (최초 1회), `npm.cmd run dev`.
4. `http://localhost:5173/`을 엽니다.

## 공간
- 중앙 서재: 원목 책장 3개, 원형 러그와 장식 테이블.
- 좌측 독서실: 의자와 러그, 창가 장식 및 독서 조명.
- 우측 개인 작업실: 원목 작업 책상, 메모 보드, 서랍장.
- x=±8 벽에 실제 통행 가능한 아치형 개구부가 있습니다. 화면의 세 구역 버튼을 누르면 해당 구역으로 이동합니다.
- 복층 분위기는 난간·보로 시각화했으며 **2층 실제 이동은 아직 지원하지 않습니다.**

## UI와 기능
- WASD / 방향키 이동, 마우스 드래그 회전. 하단 조이스틱도 조작 가능.
- 시점 버튼 클릭: 1인칭 ↔ 3인칭. 설정에서 전체 관찰 가능.
- 책 클릭: 기존 독서 기록 상세 페이지. 책 등록·수정·검색·통계 유지.
- 우측 메뉴: 내 책장은 실제 연결. 영화·여행·일기·음악은 후속 구현 예정이라는 안내 화면만 표시.
- 설정: 오후/저녁 및 맑음/비 연출, 시점, 방으로 이동.
- 초대 링크 복사: 현재 주소 복사. `localhost`는 다른 사람에게 공개되는 주소가 **아닙니다.** GitHub Pages 및 공개 Supabase 연결 후 초대 링크를 공유하세요.
- 날씨: 실제 기상 데이터가 아니라 조명 및 장식용 비 시뮬레이션입니다.

## 기록 주의
Supabase 미연결 시 로컬 저장소(LocalStorage)를 사용합니다. 브라우저 삭제 시 기록이 사라질 수 있으므로 별도 백업이 필요합니다. 방문자에게 같은 기록을 보여주려면 Supabase RLS 설정을 완료해야 합니다.

## 이번 단계의 한계
게임형 공간을 **절차적 3D 도형**으로 제작하였기 때문에 첨부한 레퍼런스 이미지의 고급 3D 아트와 동일한 수준의 재질·캐릭터·소품을 제공하는 것은 아닙니다. 3D 모델링(GLB), PBR 텍스처, 캐릭터 리깅, 정교한 애니메이션은 후속 개선 항목입니다. 실제 빌드 및 브라우저 환경에서의 카메라·충돌 테스트를 권장합니다.
