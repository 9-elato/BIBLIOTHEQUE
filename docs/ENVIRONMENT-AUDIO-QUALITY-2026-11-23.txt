자연환경 증분 개선 — 2026-11-23

기존 구현과 부족한 부분
- 식물: 셰이더 바람, 인스턴싱, 거리별 잎/풀 개수 조절, 가까운 그림자 지원. 기기별 품질 선택 부재.
- 소리: 잎·파도별 별도 AudioContext, 공간 이름으로 활성화, 2~3초 소음 반복. 새소리와 실제 위치 감쇠 부재.
- 하늘/물/암석: 구름 이동, 다중 파동 수면, 태양 반사 및 합쳐진 침식 암석 유지.

수정 기술 / 파일
- environmentAudioMix.js: 해안선과 숲 영역까지 거리로 바람/잎/물/파도/바위/새 음량 산출. 실내 차음, 작업실/바다 마루의 창밖 소리 유지.
- environmentAudio.js: 한 AudioContext, 독립 잡음 5층과 필터, 11~24초 비동기 버퍼와 불규칙 포락선, 4~16초 새소리 간격. gain.setTargetAtTime 0.8초 전환. 최초 클릭/터치/키 이후 생성, 재상호작용 시 resume 재시도, 숨김 탭 페이드, 해제 시 종료.
- ArchiveScene.jsx: 기존 두 음향 훅 대신 플레이어 좌표 기반 통합 훅 연결. 이전 소스 파일은 보존하되 호출하지 않음.
- graphicsQuality.js / useGraphicsQuality.js: 자동·PC·모바일 프로필과 저장/변경 이벤트.
- GrassField.jsx / ForestTrees.jsx: 기존 GPU 애니메이션/LOD 유지, 모바일 밀도 50%, 그림자 거리 축소.
- SceneBudget.jsx: 기존 FPS 기반 DPR 조절 유지, 모바일 상한 0.8 및 그림자 갱신 간격 제한.
- main.jsx: 환경 설정의 그래픽 품질 선택.

구현 범위와 제약
- 녹음 파일 다운로드 없이 Web Audio 합성. 저작권/다운로드 비용은 없지만 실제 새 종과 현장 녹음의 사실성을 대체하지는 않음.
- 거리 기반 혼합과 완만한 전환은 지원. 벽의 재질별 음향 반사, 회절, 정확한 실내 잔향/물리 음향 전파는 미구현.
- 모바일 밀도 감소는 그리는 양을 줄이지만 전체 식물 인스턴스 버퍼 메모리는 유지. 품질 프로필 변경 시 모델 재다운로드 없음.
- GPU 셰이더, instancing, 기존 shadow budget 유지. 모바일에서 모든 나뭇잎 그림자나 고해상도 실시간 반사를 켜지 않음.
- 자동 기기 감지는 coarse pointer 기준이며 터치 노트북은 수동 PC 선택 가능.

시간 변화 검수 방법
1. 환경 설정을 닫고 최초 클릭/터치/키 입력 후 30초 이상 기다려 소리의 강약과 새소리 간격 확인.
2. 정원에서 서쪽 해안으로 접근, 동쪽 숲으로 이동, 실내 진입: 파도/잎/새 비율과 끊김 없는 페이드 확인.
3. 맑음/장마 전환 후 잎 움직임 및 소리 강도 비교. 탭 숨김/복귀, 오디오 중단 후 재클릭 확인.
4. 같은 위치에서 PC/모바일 품질을 전환하고 30초 이동하며 풀/잎 LOD, 그림자, FPS 비교.
자동 테스트는 위치별 음량, 연속성, 바람의 시간 변화, 품질 예산을 검증. 실제 청음·브라우저 시각 검수 및 PC2 FPS 측정은 별도 필요.

검증 결과: 자동 테스트 154개 통과, 배포 빌드/에셋 검사 성공. 기존 번들 크기 경고는 유지. 실제 청음/브라우저 렌더링/FPS는 측정하지 않았으며 성능 배수 향상을 주장하지 않음.
