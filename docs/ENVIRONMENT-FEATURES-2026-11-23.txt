시간대: 따뜻한 오후 / 포근한 저녁
오후: 밝은 자연광, 푸른 하늘, 강한 바다 윤슬. 맑은 온실에서는 먼지 입자와 나비.
저녁: 낮아진 주변 밝기, 따뜻한 실내 조명, 어두워진 바다와 약해진 윤슬.
다락 하늘은 달·별·유성 표현을 사용한다. 온실은 저녁색 조명과 벽등을 사용한다.
아침·밤의 분기 일부가 코드에 남아 있지만 설정에서 선택하는 시간대는 위 두 가지다.

기념일: 없음 / 할로윈 / 크리스마스
없음: 기념일 장식 없음.
할로윈: 중앙 공간·작업실 호박, 현관의 가을 계열 장식.
크리스마스: 트리와 장식구, 현관의 겨울 계열 장식.
테마만으로 모든 공간의 날씨나 시간을 바꾸지는 않는다.

날씨: 맑음 / 장마 / 폭설
맑음: 밝은 하늘, 강한 햇빛과 윤슬, 약한 숲 바람.
장마: 흐린 색조, 줄어든 직사광·가시거리, 빗줄기와 온실 지붕 물방울,
숲 전망의 더 강한 흔들림, 약해진 윤슬. 다락에서는 별·유성이 약해진다.
폭설: 눈 입자, 차가운 풍경·안개 색조와 겨울 장식. 온실 눈은 지붕 밖에 표현.
현재 강수·적설은 시각 효과이며 모든 지형의 물리적 적설·침수 시뮬레이션은 아니다.

설정과 별개로 개인 작업실 소품은 실제 월에 따른 계절 분기를 사용하며,
폭설을 선택하면 겨울 소품으로 전환된다. 별도 계절 선택 메뉴는 없다.
