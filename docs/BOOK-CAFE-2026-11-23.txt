북카페 구현 기록
- 정원 서쪽 별관: 도서관과 별도 공간. 정원에서 동쪽 개방 출입구로 걸어 진입. 지도에 북카페 추가.
- 입구 메뉴판/카운터, 북쪽 큐레이션 서가와 굿즈 진열, 행사 포스터, 안쪽 미니 극장/상영표 구성.
- 기존 도서에서 책방지기가 선별. 최대 8권 3D 전시, 소개 목록은 전체 선택 표시. 개인 서재 도서 데이터는 변경하지 않음.
- 포스트잇·책갈피 목록, 유령 인형·안경 키링 형태의 진열 소품. 굿즈와 메뉴는 안내만 제공, 구매/결제 없음.
- 책방지기 편집: 소개글/메뉴/굿즈/행사·영화 제목 및 포스터 URL/YouTube 영상/18~23시 시작 시각.
- 날짜 전체가 3의 배수이며 목요일인 날 계산. 2026-11-12 포함. 한국 달력 기준, 장면 시간대와 무관. 시작 시각은 책방지기 직접 설정, 기본 미정.
- 영상은 상영표 패널에서 수동 재생. 실제 시각 자동 개막/3D 화면으로 동영상 투영/동시 접속 동기화는 미구현.
- 새 좌석 5개 기존 착석 시스템 연결. 벽/카운터/진열대/분리벽 충돌과 통로 확보.
- 설정 저장 범위: 현재 브라우저 localStorage. 공용 큐레이션 서버 저장은 미연결. 원격 배포에는 코드 기본값만 공유되며 개인 편집 내용은 자동 배포되지 않음.
- 포스터/상영작/큐레이션은 책방지기의 실제 선정 대기. 메뉴는 수정 가능한 초기 예시.
검증: 159개 테스트 통과(정원→북카페→극장 동선, 39개 좌석 순회 포함). 프로덕션 빌드 검증. 실제 화면·재생·청음은 미검수.
