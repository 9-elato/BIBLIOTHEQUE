코드 기반 구조·성능 점검
Computer Use 없이 소스/충돌/동선 테스트로 검증. 전체 공간에 시각 결함이 없다는 보증이나 FPS 향상 배수 측정은 아님.

확인 및 수정
1. 중앙 홀: 샹들리에 중심 y9, 기존 지지봉 상단10.7, 천장 하부16.1 사이의 공백. 지지봉을 천장까지 연장하고 고정판 추가.
2. 중앙 홀·서가 입구: x±7.3,z0 벽등이 개방 통로 중앙에 놓임. 벽이 있는 z2.65 측면으로 옮김.
3. 중앙 홀 북쪽: GRAND LIBRARY 글자가 상부 개구부 y8.6 앞에 떠 있음. 상단 벽 y11.2로 부착.
4. 북카페: 펜던트 봉의 상단6.4와 천장 하부6.975 사이 공백을 연결. 메뉴판 후판과 천장 지지봉 추가.
5. 북카페 진열 책: 2단 받침판 추가, 굿즈 상판 추가와 유령 인형·포스트잇 높이 보정.
6. 미니 극장: 스크린 상부 고정 몰딩, 스크린 돌출부까지 충돌 확장.
7. 카운터: 상판이 본체보다 넓은 차이를 충돌 범위에 포함. 기존 출입구와 39개 좌석의 안전 하차 경로 유지.
8. 카메라: 얇은 책 이미지와 표찰은 별도 카메라 장애물에서 제외. 물리 책/벽/가구는 계속 차단.
9. LOD: 먼 잎이 3배 이상 커질 수 있던 보상 비율을 최대1.5로 제한, 프레임 독립 보간으로 크기 변화 완화.
10. 성능: 북카페 정적 외피·좌석·조명 메시 배치 병합. 클릭하는 진열 영역은 병합에서 제외. 숲·바다 창문 갱신 초당24회, 태양 위치 임시벡터 재사용.

유지되는 기능
기존 문·계단·사다리·착석/하차·책 선택·큐레이션 편집을 유지. 상호작용 노드를 무작정 합치지 않음. 균형형 거리LOD가 기존 기본이며 품질 선택을 사용자에게 질문 중.

추가 논의
- 기본 품질: 균형 / 속도 / 디테일 우선
- 충돌: 벽을 따라 미끄러지는 현재 이동감 / 접촉 즉시 정지
- 구체적인 미마감 물체 위치를 받아 다음 점검 대상 확정
- 제안: 한 개의 가구 배치 데이터에서 보이는 메시·충돌·착석점을 함께 생성해 향후 수정 시 어긋남 예방
- 제안: 문 회전 범위·계단 층고·조명 부착점을 검사하는 개발용 표시 기능
- 제안: 고정된 장소와 카메라로 PC1/PC2 성능 비교. 지금은 실행 FPS를 측정하지 않았음.
