BIBLIOTHEQUE — 300단계 실행 기록

범위: 성능 1차, 온실 문 2차, 나머지 문 3차, 좌석 접근·하차 4차 수정. 300단계 전체 완료 아님.

001-01 / 001-03: 실제 렌더 해상도·브라우저·DPR·시점·기기 메모 기록.
001-07 / 001-08: 2초 준비 후 30초 벽시계 기반 수집, P50/P95와 긴 정지 기록.
001-09: 최근 30회 결과를 JSON으로 다운로드.
001-10: 측정 중 탭 숨김 발생 시 취소·무효 처리.
010-01: 상호작용 안내 탐색을 약 10Hz로 제한. E/클릭 실행은 현재 상태를 즉시 판정.

002-01 / 002-02: E/클릭의 탐색 시간·실행 시간·다음 rAF 콜백 지연을 분리.
최근 100회 입력 기록을 프레임 측정 결과와 함께 JSON으로 다운로드.
014-02 / 014-04 / 014-05 / 014-10: 온실 문에 반대쪽 열림·회전 경로 검사·늦은 진입 감지 적용.
014-03 / 014-04 / 014-05: 작업실·현관·바다 마루에도 이동 중 끼임 검사 추가.
현관문 시각 회전과 충돌 판정을 같은 amount로 연결. 열림 플래그만으로 통과하지 않음.
지하 캐릭터가 지상 문을 멈추게 하지 않도록 층 높이를 구분.
음악·미니게임·망원경 E 실행 시 최신 콜백을 사용하도록 수정.
전체 014단계는 실제 화면과 양방향 개폐 검수까지 진행 중.
111-07: 온실 입구 양방향 근접 개방 테스트 통과. 실제 시각 검수 대기.

015-06 / 015-07 / 243-08 / 243-09 / 245-06: 좌석 진입점까지 중간 경로를 검사.
지정 진입점을 거쳐 앉고 일어나도록 변경. 바닥 구간에서는 보행 상태 사용.
하차 원점이 멀거나 중간이 막히면 가까운 안전 후보를 선택.
모두 막히면 앉은 상태를 유지하고 안내하며 공간 확보 후 재시도 가능.
245-07은 제한된 후보 검사만 구현했으므로 진행 중. 임의 장애물 우회 탐색과
착석 전환 중 새 장애물 발생 대응은 아래 5차에서 바닥 경로에 적용.

5차: 착석·하차 전환 중 바닥 경로를 재검사. 새 장애물이 생기면 현재 위치와
자세·진행 시간을 유지하고, 공간이 비면 이어서 이동. 대기 안내를 표시.
침대 하차 중 누운 각도·높이 유지, 긴 프레임, 기존 33개 좌석의 정상 전환 검증.
검사 범위는 바닥 연결 경로와 하차 지점이며, 좌석 자체 쿠션 구간은 제외.
임의 장애물 우회 및 새 가구가 쿠션 구간을 침범하는 경우는 아직 미구현.

검증: 자동 테스트 127개 통과, Vite 빌드 및 모델 압축 통과.
PC2 실제 FPS·E 입력 지연·화면 QA는 아직 측정하지 않음.
따라서 위 항목은 검수 중이며 완료로 기록하지 않음.
Git push 및 공개 배포는 수행하지 않음.

측정: 실행 주소에 ?perf 추가 → 공간과 기기 조건 선택 → 측정 시작.
32초 동안 활성 창 유지. 같은 해상도·시야·기기·전원·캐릭터로 전후 비교.
renderP50은 CPU의 렌더 호출 시간이며 GPU 완료 시간은 아님.
nextFrameCallbackMs는 다음 콜백까지의 시간으로, 화면 표시 완료나 GPU 완료 시간이 아님.

문 개폐 실제 화면·가구 이동 및 하차 지점 안전 경로 재검증.
