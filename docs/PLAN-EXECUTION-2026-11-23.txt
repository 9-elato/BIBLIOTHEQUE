6차 — 하차 바닥 우회 및 자동 점검 복구

015·245: 좌석 앞 착지점부터 기존 출발점으로 이어지는 직선이 막혔을 때
0.2m 격자에서 가까운 우회 경로를 탐색한다. 모든 연결 구간은 기존
walkHeight/movePlayer 충돌 검사를 사용한다. 목적지는 1.05m 이내,
탐색은 최대 169개 지점과 2.8m 격자 경로로 제한한다.
좌석에서 먼저 천천히 내려온 뒤, 바닥 우회 경로를 0.85m/s로 걷는다.
우회 중 새 장애물이 생기면 현재 위치를 유지하고 최대 약 0.3초 간격으로
다시 탐색한다. 길이 없으면 멈춘다. 프레임마다 전체 탐색하지 않는다.

다음 단계: 자동 가구 점검에서도 실제 전환 충돌 검사를 실행한다.
시간 초과 시 쿠션 내부에서 착석 상태만 해제하던 처리를 수정했다.
검증된 접근 위치 또는 시작 위치로 복구하며, 둘 다 막히면 상태를 보존한다.
이는 개발용 자동 점검의 복구이며 일반 플레이 중 순간이동은 추가하지 않았다.

검증: 131개 테스트 통과. Vite 및 모델 압축 빌드 통과.
33개 좌석 정상 접근·착석·하차, 새 장애물 우회, 이동 중 재탐색,
탐색 범위 제한, 자동 점검 실패 복구를 검사했다.

제한: 좌석 바로 앞 착지점 자체가 막혔으면 대기한다. 가구를 가로지르는
임의 대체 착지는 허용하지 않았다. 쿠션 구간을 새 가구가 침범하는 경우,
실제 PC2 화면·FPS·입력 지연 측정은 남아 있다. Push/배포하지 않았다.
300단계 전체 완료 또는 정량 완성도를 의미하지 않는다.

테라스·숲 온천 후속 통합 검증
- 테라스 소파 좌석을 추가하여 총 34개 좌석의 접근·착석·하차 검사에 포함했다.
- 테라스에서 V 키/하늘 보기 버튼으로 개방된 하늘 방향을 볼 수 있다.
- 소파·탁자·콘솔·푸프 충돌을 유지하며 중앙 통로와 소파 옆 통로 왕복을 검사했다.
- 온천 정적 장식 묶음 렌더링, 비활성 공간의 수증기 갱신 생략과 24Hz 갱신 제한.
- 원격 PC2의 확장된 테라스·온천, 안내도, 아바타 및 카메라 개선을 병합 보존했다.
- 137개 자동 검사 및 Vite/모델 압축 빌드 통과. 큰 JS 청크 경고는 남아 있다.
- 실제 Chrome 화면 비교와 FPS 측정은 프로젝트 창을 열어 주시면 이어서 진행한다.
- 공개 배포는 사용자 요청 순서에 따라 화면 검수 이후 진행한다. 아직 Push하지 않았다.
