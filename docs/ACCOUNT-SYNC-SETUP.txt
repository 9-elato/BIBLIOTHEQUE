기록 연동 설정 및 검증 (2026-11-26)

현재 상태
- 클라이언트 동기화 코드와 SQL 마이그레이션을 준비했습니다.
- 로컬 .env에는 서버 설정이 없고 실제 Supabase 관리 연결이 제공되지 않았습니다.
- 따라서 실제 서버 적용, 계정 로그인, PC1/PC2/모바일 간 종단 검증은 아직 완료하지 않았습니다.

설정 순서
1. 기존 Supabase 프로젝트 SQL Editor에서 supabase/account-records-migration.sql을 실행합니다.
2. 기존 books 테이블에는 supabase/book-metadata-migration.sql의 필드도 필요합니다.
3. Supabase Auth에 사용할 계정이 있는지 확인합니다. 모든 기기에서 같은 계정을 사용합니다.
4. GitHub 저장소 Settings > Secrets and variables > Actions > Variables에
   VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY, VITE_OWNER_UID를 설정합니다.
   VITE_OWNER_UID는 책방지기 계정 UUID입니다. service_role 비밀 키를 넣지 않습니다.
   로컬 개발은 .env.example을 참고해 .env에 같은 공개 연결 정보를 넣습니다.
5. 변경본을 배포하고 사이트 환경 설정에서 로그인합니다.
6. 각 브라우저에서 먼저 전체 기록 백업을 내려받습니다.
7. 각 기기의 '이 브라우저의 기존 기록 합치기'를 실행합니다. 원본은 삭제하지 않습니다.
8. 예전 로컬 책은 책방지기 계정으로 '기존 책을 서버에 추가'를 실행합니다.
   서버에 없는 ID만 추가합니다. 같은 ID는 서버본을 유지하므로 차이가 있다면 백업과 비교해 편집해야 합니다.
9. '동기화 완료'를 확인한 뒤 다른 기기에서 동일 계정으로 로그인해 확인합니다.

동기화 범위
- 책 목록, 책등/표지, 독서 감상과 별점: 기존 books 서버 저장 및 15초/창 복귀 갱신.
- 북카페 메뉴, 큐레이션, 굿즈, 포스터, 상영 설정: 계정별 저장.
- 서재 출석, 유령단 발도장과 등급, 기프트 선택, 느린 편지, 독서 시간, 책 배치, 메모: 계정별 저장.
- 캐릭터, 작업실 조명, 환영 탭 상태도 저장합니다.
- 그래픽 품질은 기기의 성능에 따라 달라야 하므로 기기별 설정을 유지합니다.
- 영화/여행 기록은 기존 화면 자체가 아직 저장 기능 없는 안내 화면입니다.

병합 규칙
- 출석 날짜/발도장은 중복을 제거하고 합칩니다. 편지는 ID별로 합칩니다.
- 독서 시간은 마지막 동기화 이후 증가분을 더합니다. 첫 가져오기는 중복 방지를 위해 큰 누적값을 사용합니다.
- 서로 다른 설정 필드는 함께 보존합니다. 같은 필드의 충돌은 업로드하는 기기의 변경을 우선합니다.
- 서버 버전 비교 저장으로 경쟁 갱신 시 다시 읽고 병합합니다.
- 원격 적용 직전 로컬본은 library-sync-backup:<계정ID>에 보관합니다.
- 모든 중간 버전을 무기한 보관하는 이력 저장소는 아닙니다. 중요한 기록은 JSON 백업을 권장합니다.
- 오프라인 중 계정별 기록은 로컬에 남고 복귀 시 재시도합니다. 기존 books 편집은 온라인 서버 저장이 필요합니다.
- 큰 포스터 파일은 바뀐 버전일 때만 내려받도록 버전을 먼저 확인합니다.

공개/비공개 주의
- 기존 books 테이블은 프로젝트의 기존 설계대로 책과 독서 감상을 공개 열람합니다.
- 새 account_records 테이블은 로그인한 본인만 읽고 쓸 수 있도록 RLS를 적용합니다.
- 북카페 설정도 현재는 같은 계정의 기기 간 연동입니다. 로그인하지 않은 방문객에게 설정을 공개 배포하는 별도 발행 기능은 포함하지 않았습니다.
- 비밀번호, 로그인 토큰, 서비스 비밀 키는 동기화 대상에 포함하지 않습니다.

웰컴 기프트
- 최초 9회 방문 후: 멤버십 카드 + 유령단 편지 + 키링/책갈피 택1.
- 멤버십 화면에서 굿즈를 선택하고 북카페 방문 시 책방지기에게 화면을 보여줍니다.
- 실물 재고/수령 확인은 자동 처리하지 않습니다. 다음 단계로 책방지기 수령 확인 기능을 추가할 수 있습니다.

실기기 확인 항목
- PC1의 도장과 편지가 PC2/모바일에 나타나는지.
- 서로 다른 기기의 동시 도장/편지 작성이 모두 남는지.
- 독서 시간 누적, 기프트 선택, 메뉴 수정이 갱신되는지.
- 로그아웃/다른 계정 로그인 시 이전 계정의 편지가 보이지 않는지.
- 네트워크 중단 시 대기 표시, 재연결 시 완료 표시가 바뀌는지.
