# 서가의 온도 — 3D 가상 개인 서재

ChatGPT + VS Code + GitHub로 운영할 수 있는 **React + Three.js 기반 가상 서재**의 초기 프로젝트입니다.

## 현재 구현된 기능
- 정원·현관·중앙 홀·6장르 서가·라운지·2층 갤러리·열람실·다락·비밀 작업실 탐험
- 유령 GLB, 책을 띄워 들고 읽기, 장르별 책장 칸·3개 테이블 배치와 브라우저 저장
- WASD/터치 이동, 드래그 시점, 1·3인칭, 근접 E와 터치 상호작용
- 1층·2층·다락 안내도, 중앙/다락 계단의 연속 보행, 층별 벽·가구 충돌
- 도서 등록·수정·삭제·검색·감상·평점·완독일·표지 URL
- 브라우저 로컬 저장, 선택적 Supabase 연결, AI 토론 프롬프트 복사

현재 코드와 기획의 차이, 수정 순서, 정리 내역은 [PROJECT-AUDIT.md](PROJECT-AUDIT.md)를 기준으로 확인하세요. [WORLD-ROADMAP.md](WORLD-ROADMAP.md)는 장기 기획입니다.

## 2026-11-20 업데이트

중앙 홀 서쪽의 긴 계단으로 2층에 걸어 올라갑니다. 2층 남서쪽 연결 계단은 다락으로 이어집니다. 계단에서는 E를 누르지 않아도 됩니다. 지도와 방 메뉴는 빠른 이동용으로 유지했습니다.

책 상세의 **책의 자리**에서 책장·칸 또는 테이블을 선택해 배치를 저장할 수 있습니다. 책을 든 채 테이블/서가 가까이에서 E를 눌러 빈자리에 놓을 수도 있습니다. 배치는 현재 브라우저와 사이트 주소에 저장되며, 아직 Supabase 기기 간 동기화 대상은 아닙니다. 저장 실패는 화면에 표시합니다.

자세한 검증과 제한은 [MOVEMENT-AND-PLACEMENT.md](MOVEMENT-AND-PLACEMENT.md)를 참조하세요.

## 1. 개발 프로그램 설치 (Windows 기준)
1. [Node.js](https://nodejs.org/) LTS를 설치합니다. Vite 6은 Node 18 이상을 지원하지만, 새 설치에는 Node 22 LTS를 권장합니다.
2. [VS Code](https://code.visualstudio.com/) 설치.
3. [Git](https://git-scm.com/) 설치 및 [GitHub](https://github.com/) 회원가입.
4. ZIP 압축 해제 후 VS Code에서 `파일 > 폴더 열기`로 `my-virtual-library` 폴더를 엽니다.
5. `터미널 > 새 터미널`에서 아래 명령을 실행합니다.

```bash
npm install
npm run dev
```

표시된 URL(일반적으로 `http://localhost:5173/`)을 브라우저에서 열어 확인합니다.

## 2. 로컬 체험 모드

Supabase 설정 전에는 각 브라우저의 `localStorage`에 책이 저장됩니다. **웹사이트가 공개되더라도 방문자 사이에 데이터가 공유되지 않습니다.** 다른 기기에서 보이지 않으며 브라우저 저장 공간을 지우면 사라질 수 있습니다. 이 모드는 학습/시안 확인용입니다.

## 3. Supabase 연결 — 공개 열람 + 소유자만 수정

1. [Supabase](https://supabase.com/)에서 프로젝트를 만듭니다.
2. Authentication → Users에서 **자신의 관리자 계정**을 만듭니다. 이메일 인증 등 프로젝트 설정을 확인하세요.
3. 관리자 사용자 UUID를 복사합니다.
4. `supabase/schema.sql`의 `YOUR_OWNER_AUTH_UID` 3곳을 그 UUID로 바꾸고 SQL Editor에서 실행합니다. **SQL에 실제 UUID를 입력한 뒤 실행해야 합니다.** SQL 실행 전에 테이블 또는 정책이 이미 생성되어 있으면 중복 정책 오류가 날 수 있습니다.
5. 프로젝트의 URL과 publishable/anon 공개 키를 확인합니다. **service_role 또는 secret 키는 웹사이트에 입력하지 마세요.**
6. `.env.example`을 복사하여 `.env`를 만들고 다음처럼 설정합니다.

```dotenv
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
VITE_OWNER_UID=YOUR_OWNER_AUTH_UID
```

7. 개발 서버를 다시 실행합니다. `서재 관리`에서 로그인한 뒤 책을 등록합니다. 새로 연결한 빈 DB에는 예시 책이 표시되지 않는 것이 정상입니다.
8. 로그아웃 후에도 등록된 책이 보이는지, 다른 브라우저에서는 **읽기만 가능**한지 확인합니다.

보안: 브라우저에 관리자 UUID가 노출되더라도 인증된 실제 계정의 `auth.uid()`는 위조할 수 없도록 RLS로 제한합니다. 공개 DB의 책과 감상은 누구나 열람 가능하므로 개인 연락처나 비공개 메모는 입력하지 마세요.

## 4. GitHub Pages 배포

1. GitHub에서 **새 공개 저장소**(예: `my-virtual-library`)를 만듭니다. README 자동 생성은 해제해도 됩니다.
2. 프로젝트 폴더에서 터미널을 열고 순서대로 입력합니다.

```bash
git init
git add .
git commit -m "Create 3D reading room"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/my-virtual-library.git
git push -u origin main
```

3. GitHub 저장소 → Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다.
4. Supabase 사용 시 저장소 → Settings → Secrets and variables → Actions → **Variables**에 아래 3개를 생성합니다.
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY` (공개 키만)
   - `VITE_OWNER_UID`
5. Actions 탭에서 `Deploy to GitHub Pages` 실행 상태를 확인합니다. 주소는 일반적으로 `https://YOUR_USERNAME.github.io/my-virtual-library/`입니다.
6. 개발한 내용을 수정한 뒤 `git add . && git commit -m "Update library" && git push`로 재배포할 수 있습니다.

`vite.config.js`가 GitHub 저장소 이름에 맞춰 기본 경로(base)를 자동 지정합니다.

## 5. AI 독서 토론 기능

현재 구현은 **책 선택 → 독서 감상 기반 프롬프트 복사 → ChatGPT에서 대화**하는 안전한 초기 형태입니다. 실제 웹사이트 내부에서 방문자가 AI와 대화하려면 서버 측 프록시(예: Supabase Edge Function)를 만들고, OpenAI API 키는 **서버 비밀 환경변수**로만 보관해야 합니다. 방문자 인증, 요청 횟수 제한, 예산 상한, 입력 길이 제한, 악용 방지 정책을 별도로 설계하세요. **GitHub Pages는 정적 호스팅이므로 서버에서 API 키를 숨길 수 없습니다.** ChatGPT 구독과 OpenAI API 사용 요금은 별도일 수 있습니다.

## 7. 앉아서 독서하기 (2026-11-20)

라운지 12자리, 2층 열람실 의자 2자리, 다락 의자 2자리와 데이베드 1자리, 총 17자리에서 사용할 수 있습니다. 좌석 앞에 가까이 가면 `E` 안내가 나타납니다. 책을 들고 `E`를 누르면 자리로 이동해 앉고, 책을 펼쳐 읽습니다. 빈손으로 앉았다면 **앉아서 읽을 책 고르기 → 책 선택 → 책 들고 돌아가기**로 독서를 시작합니다. 다시 `E`를 누르면 책을 가진 채 안전한 바닥 위치로 일어섭니다. 터치 화면에서는 동일한 상호작용 버튼을 누릅니다.

- 착석 1.05초, 기립 0.9초 동안 위치·높이·몸 방향을 부드럽게 보간합니다. 중간 연속 입력과 보행은 막고, 완료 후 다시 걸을 수 있습니다.
- 유령의 하단과 몸통 형태를 변형하고 독서 시 살짝 앞으로 기울입니다. 책은 펼쳐지는 동작과 주기적인 페이지 넘김이 있습니다. GLB의 복제된 지오메트리만 변경하며 원본 모델은 유지합니다. 골격 애니메이션이나 천 물리 시뮬레이션은 아닙니다.
- 기록 창을 열거나 창 포커스를 옮겨도 착석은 유지됩니다. 방 바로 이동은 착석을 해제합니다. 착석 상태 자체는 새로고침 후 저장하지 않습니다. 기존 책 배치 저장은 별도로 유지됩니다.
- 라운지는 원목 다리·쿠션·버튼 장식·황동 스터드·담요를 추가했습니다. 석조 아치 벽난로, 움직이는 불꽃, 황동 스탠드, 러그, 벽 패널, 커튼과 액자를 구성했습니다. 딥그린 소파는 벽난로를 가리지 않는 측면에 배치했습니다.
- 새 스탠드에도 보행 충돌을 적용했습니다. 가구 위치와 착석 위치는 공통 배치 정의를 따릅니다. 라운지에서는 전체 조명을 낮추고 벽난로와 스탠드의 따뜻한 빛을 강조합니다.

검증: `npm test` 22개 통과(17개 좌석 접근·높이·복귀, 층별 계단 입구에서 좌석까지 충돌 없는 경로 탐색, 전환 중 중복 입력 방지, 기존 계단/충돌/책 저장 포함). 브라우저에서 열람실과 다락 의자의 독서·기립·보행, 다락 데이베드 착석·기립, 다락↔2층 계단 연속 왕복을 확인했습니다. 브라우저 오류는 없었습니다. 빌드 시 기존 단일 번들 크기 경고는 남아 있습니다.

## 8. 열람실·다락의 동화책 분위기

- 열람실: 책상을 마주 보는 세이지·버건디 의자, 녹색 유리 독서등, 가죽 상판, 잉크병·깃펜, 테두리 러그, 커튼과 창틀, 황동 벽등·선반 장식. 저장된 책을 놓는 칸은 비워 두었습니다.
- 다락: 빈백을 두 안락의자로 교체하고 데이베드를 원목색으로 마감했습니다. 별빛 색상의 러그, 쿠션·담요, 황동 천체 모형, 별자리 액자, 캐비닛 등과 벽등, 천창의 차가운 빛을 함께 사용합니다. 영화 감상용 스크린은 크기를 줄여 유지했습니다. 기존 러그 중복과 북쪽 벽 마감도 정리했습니다.
- 중앙 홀·갤러리에는 액자, 북쪽 복도에는 러너와 벽등, 현관 콘솔에는 책과 필기 소품을 추가했습니다. 바닥 동선을 막는 새 장식 가구는 추가하지 않았습니다.
- 유령 GLB에는 원래 `GHOST_Eye_L/R` 메시가 있습니다. 눈을 천 표면보다 조금 앞으로 옮기고 책 높이를 낮춰 독서할 때 두 눈이 보이도록 했습니다. 에셋 검사에 몸과 양쪽 눈의 존재 확인을 추가했습니다.
- 치즈냥이 캐릭터·클릭 처리·소개 패널을 제거했습니다. 현재 장면에는 고양이가 없습니다.

장식은 Three.js 모형과 재질로 구성했습니다. 천창과 창문 색은 가상 시간대 연출이며 실제 야외 풍경이나 영상 재생을 추가한 것은 아닙니다.

## 9. 중앙 홀·서가·복도 및 표지 연동

- 중앙 홀: 황동 샹들리에, 테이블 앞판·모서리 장식, 식물 모티프 액자를 추가했습니다. 기존 테이블의 충돌 범위와 책 배치 칸은 유지합니다.
- 장르별 서가: 장르 색상의 등, 북엔드, 액자, 필기 소품과 천장·보를 추가했습니다. 실제 광원은 가까운 장르 구역을 중심으로 켜집니다. 중앙 통로에는 새 가구를 두지 않았습니다.
- 북쪽 복도: 천장·보·벽 마감과 액자를 보강하고, 기존 벽등을 벽 안쪽 면으로 옮겨 보이게 했습니다.
- 라운지 아치 출입: 중앙 계단의 평면 영역 전체가 1층 통행을 막던 문제를 수정했습니다. 계단 높이가 2.2m 이상인 부분 아래는 1층으로 통과하고, 낮은 계단 아래와 상층 난간은 계속 막습니다. 라운지 바로 이동 지점도 좁은 의자 옆에서 아치 앞의 빈 공간으로 옮겼습니다.
- 현관 초록 선: 잔디 윗면을 실내 바닥보다 낮추고, 바깥 보도와 문턱의 범위를 정리해 실내 바닥과 잔디가 같은 높이로 겹치지 않도록 했습니다.
