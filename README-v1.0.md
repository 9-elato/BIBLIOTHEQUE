# My Little Library v1.0 — 모바일·도서 상태·여우 캐릭터

## 설치
- 기존 v0.9 프로젝트를 백업하세요.
- 업데이트 ZIP의 `src/main.jsx`, `src/ArchiveScene.jsx`, `src/style.css`를 기존 `src`에 덮어쓰세요. `src/data.js`는 유지합니다.
- 터미널: `npm.cmd run dev`
- 개발용 주소: `http://localhost:5173/`

## 추가 기능
1. 모바일 레이아웃 및 화면 터치 드래그로 시선 회전, 누르고 있는 동안 동작하는 화면 방향키.
2. 황동색 띠와 ✦ 표식이 있는 책은 데이터가 연결된 책, 표식 없는 책은 장식용 책. 누르면 기록 상세 정보 표시.
3. 방 바로 이동 버튼을 상단으로 이동. `방 메뉴 숨기기` 버튼 및 설정 메뉴에서 표시/숨김 가능. 브라우저에 설정 기억.
4. 여우 캐릭터: 주황색 몸통, 뾰족한 귀, 꼬리, 걷기 동작을 기본 도형으로 제작. 1인칭에는 숨기고 3인칭에 표시.

## 중요한 공개/모바일 접속 조건
`http://localhost:5173`은 현재 개발 PC에서만 접근되는 주소이며, 스마트폰에서 같은 문자열로 접속할 수 없습니다. 같은 Wi-Fi에서 테스트하려면 터미널의 `Network: http://192.168.x.x:5173` 같은 주소를 스마트폰에서 열어야 하고, PC 방화벽 및 네트워크 격리 설정에 따라 실패할 수 있습니다. 인터넷 어디서나 동일 URL로 접속하려면 GitHub Pages 등에 정적 사이트를 배포해야 합니다. 공개 배포 후에는 하나의 HTTPS 주소를 PC와 모바일에서 사용할 수 있습니다.

GitHub Pages: 저장소의 Settings > Pages > Build and deployment에서 GitHub Actions를 선택하고 배포 워크플로를 실행합니다. 단순히 소스 파일을 업로드한 것만으로 Vite 프로젝트가 자동 실행되는 것은 아닙니다. DB 연결 없이 로컬 저장 모드라면 기기 간 독서 기록은 동기화되지 않습니다. 공유 기록은 Supabase 같은 DB를 별도로 연결해야 합니다.

## 인테리어 콘셉트 기록
- **현재 (v0.9~1.0):** 크림색 벽, 햇빛이 들어오는 아치형 창문과 밝은 원목 바닥을 기반으로, 중앙 서재와 좌측 독서실·우측 개인 작업실이 아치형 통로로 연결된 따뜻한 게임형 공간이며, 가구·식물·러그·층고가 높은 서가를 통해 편안하고 생활감 있는 개인 도서관을 표현한다.
- **이전 (v0.5~0.8):** 깊은 녹색 벽과 짙은 월넛 책장, 앤티크 황동 조명을 중심으로 고딕 아치와 비밀 서가, 벽난로 라운지, 안개 낀 창밖 풍경을 결합한 클래식 아카이브·다크 아카데미아 혼합형 공간으로, 신비롭고 고풍스러운 탐색 경험을 강조한다.

## 구현 범위와 한계
- 동물 캐릭터는 기본 Geometry 모델이며, 고해상도 애니메이션 GLB는 아닙니다.
- UI와 터치 입력은 구현되어 있지만 실제 iOS/Android 브라우저 검증은 별도 필요합니다.
- 실제 시간/날씨 연동이나 온라인 실시간 방문자 초대는 아직 없습니다. `친구 초대`는 링크 복사만 수행합니다.

## GitHub Pages에서 PC/모바일 동일 URL 사용하기
1. GitHub에서 공개 저장소를 새로 만들고 이 프로젝트의 **내용 전체**를 저장소 루트에 업로드합니다 (`src`, `index.html`, `package.json`, `.github` 포함).
2. 기본 브랜치가 `main`인지 확인합니다.
3. 저장소 `Settings > Pages > Build and deployment > Source`에서 **GitHub Actions**를 선택합니다.
4. `Actions` 탭의 **Deploy My Little Library to GitHub Pages** 워크플로 실행 결과를 확인합니다.
5. 정상 배포 후 `https://<github-username>.github.io/<repository-name>/` 형식의 링크를 PC와 스마트폰에서 동일하게 엽니다.

**주의:** GitHub 저장소에 `.env`나 비밀 키를 업로드하지 마세요. Supabase 연결 시 공개 가능한 anon key와 RLS 정책을 별도로 점검해야 합니다. 공개된 페이지의 `친구 초대`는 링크 복사이며 다중 사용자 동시 접속 기능은 아닙니다.
